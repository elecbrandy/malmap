# 프론트엔드 (frontend/)

최상위 `AGENTS.md`의 전역 규칙을 먼저 따른다. 아래는 이 영역의 추가 규칙.

## 성격

이 게임의 정체성은 프론트엔드에 있다(백엔드는 숫자만 돌려줌). 렌더링·인터랙션 완성도가 중요하지만, "복잡하게"라는 뜻은 아니다 — 오버엔지니어링 금지는 여기서도 유효.

**개발 순서를 지킨다.** M3(지도 없이 검색창 + 텍스트 결과)를 건너뛰고 M4(지도)로 가지 않는다. 지도는 무거우니, 그전에 핵심 루프(검색→채점→다음 추측)가 재밌는지부터 검증한다.

## 렌더링

타일 수백~1천여 개 + 잦은 카메라 팬/줌/애니메이션 조건에선 순수 SVG/DOM은 리렌더링 비용이 크다. **react-konva(Canvas)로 시작**, 프레임 저하가 확인되면 pixi.js(WebGL)로 올린다(처음부터 WebGL로 과하게 가지 않음). 렌더링 레이어를 게임 상태와 분리해, 렌더러를 바꿔도 상태 로직을 안 건드리게 한다.

## 상태 관리

**zustand** 정도로 충분(Redux 보일러플레이트 금지). 전역: 검색 기록, 카메라 위치/줌, 오늘의 지도 데이터, 하이라이트 타일. 로컬로 충분한 것(입력창 텍스트)은 전역에 올리지 않는다.

## 유사도 색상 (빨강–흰색–연두 발산형)

타일 색은 유사도를 **빨강(오답, 낮음) → 흰색(중간) → 연두(정답, 높음)** 3색 발산형(diverging)으로 표현한다. 규칙:

- **색 매핑 로직·임계값은 상수 모듈 한 곳**에서만 관리한다. 여러 파일에 흩뿌리지 않는다.
- **비선형 매핑**: 유사도를 색에 선형 대응하지 않는다. 승부처인 높은 구간(대략 0.7~1.0)을 흰색→연두 사이에 넓게 펴서, 후반의 미세한 점수 차(0.85 vs 0.91 vs 0.94)가 초록 농담으로 드러나게 한다. 선형으로 하면 대부분 단어가 빨강~흰색에 몰리고 정작 중요한 초록 구간이 좁아진다.
- **명도도 함께 움직인다**: 빨강은 살짝 어둡게, 연두는 살짝 밝게, 중간은 밝게. 색상(hue) 구별이 안 되는 사용자(적록색맹)도 명도로 구별할 수 있게 하기 위함. 순수 빨강/초록보다 주황빛 빨강 ↔ 청록빛 연두로 살짝 틀면 색맹 구별력이 올라간다.
- **숫자를 항상 함께 표시**: 색은 보조 신호이고 정확한 정보는 숫자(유사도)가 준다. 색만으로 정보를 전달하지 않는다(접근성).
- **중간값이 배경에 묻히지 않게**: 배경이 흰색이므로 중간값 타일엔 옅은 테두리를 주거나 순백(#FFF)이 아니라 아주 연한 회색을 쓴다.

## 컴포넌트 규칙

**SearchBar** — `POST /guess` 호출. `<form>` 사용 시 `preventDefault`. 같은 단어 중복 검색은 재요청 대신 기존 결과로 점프(API 절약).

**Tile** — 엔트리 하나 = 타일 하나. 표기 + 뜻풀이 일부 + 유사도 표시. **동음이의어는 각각 별도 타일**(합치지 않음). 색은 위 "유사도 색상" 규칙을 따른다.

**MapCanvas** — 흰 화면에서 시작(포그 오브 워), 발견된 타일만 드러남. 새 결과로 **부드럽게 팬/줌**(의미 공간을 가로지른 감각), 단 **스킵/즉시이동 옵션** 제공. 동음이의어처럼 먼 두 지점이 켜지면 둘 다 반짝이고 카메라는 점수 높은 쪽으로.

**ResultStack** — `on_map=false` 엔트리를 하단/사이드 카드로. **유사도 높은 순 정렬**(검색 순 아님). 지도 엔트리도 이 리스트에 함께 넣되 지도 유무를 아이콘/색으로 구분. 항목 클릭 시 해당 타일로 카메라 점프("길 잃음" 방지).

**MiniMap** (M4 이후) — 전체 축소판에 발견 타일 표시. 편의 기능이니 핵심 루프 후 얹음.

## API 연동

`api/client.ts`에 호출을 모은다(컴포넌트에서 `fetch` 흩뿌리지 않음). 응답 타입을 TS로 정의하고 백엔드 필드명은 `AGENTS.md` 용어 사전을 따름(entry/sense/similarity/on_map). 로딩/에러를 UI로 처리(조용히 삼키지 않음), 사용자 메시지는 한국어.

## 하지 말 것

- M3(텍스트 결과)를 건너뛰고 지도부터 만들기
- 동음이의어를 한 타일로 합치기
- 유사도를 색에 선형 매핑(높은 구간이 뭉개짐)
- 색만으로 유사도 전달(숫자 없이)
- 색 임계값/좌표 변환 상수를 여러 파일에 중복
- 성능 문제 확인 전 WebGL/최적화로 과하게 가기
- 이 규모에 Redux 도입
