# 데이터 파이프라인 (pipeline/)

최상위 `AGENTS.md`의 전역 규칙을 먼저 따른다. 아래는 이 영역의 추가 규칙.

## 성격

웹 서버와 분리된 **오프라인 배치 작업**이다. FastAPI 앱을 import하지 않는다(DB 스키마만 공유). 각 단계는 독립 실행 스크립트로 나누고, 각 단계는 입력 파일을 읽어 출력 파일을 남긴다 — 중간부터 다시 돌릴 수 있고 산출물을 눈으로 검증할 수 있어야 한다. 거대한 단일 스크립트를 만들지 않는다.

## 단계

```
원본 → [1]parse → entries_raw.jsonl
     → [2]filter → entries_filtered.jsonl
     → [3]embed → entries_embedded.jsonl
     → [4]project → entries_with_coords.jsonl
     → [5]load → Postgres
```

**[1] parse** — 국립국어원 실제 배포 포맷을 먼저 확인한다(추측으로 파서 작성 금지). 표제어/품사/의미번호(sense_no)/뜻풀이/빈도를 추출. 뜻풀이는 의미번호별로 이미 나뉘어 있으니 **평탄화하지 말고 유지**(각 뜻 = 하나의 entry). `encoding="utf-8"` 명시.

**[2] filter** — 데이터 품질을 좌우하는 단계. 명사만 남기고, 의존명사("것/수/바" 등) 제외, 빈도 하위 제외(상위 N개/N%). 빈도 정보 없으면 사용자와 대안 상의. 각 단계 통과 개수를 로그로 출력("3만 → 1.2만 → 8천").

**[3] embed** — **표제어가 아니라 뜻풀이 문장을 임베딩**(동음이의어 분리의 핵심). 뜻풀이가 짧으면 `"밤: 밤나무의 열매"`처럼 표제어를 붙이는 것도 실험. 모델은 **라이선스 apache-2.0/mit 명시된 것만**(확인 결과를 주석/커밋에 남김). `model.encode()`에 리스트를 통째로 넘겨 배치 처리(한 개씩 루프 금지). 벡터 차원은 한 곳에서 관리(DB `VECTOR(n)`과 일치).

**[4] project** — 전체 사전 entry를 UMAP 2D로 투영해 모두 고정 좌표를 갖게 한다. UMAP은 국소 이웃은 보존하나 전역 거리는 왜곡 — 좌표는 "이웃 힌트", 색깔(유사도)이 "정확한 정보"라는 역할 분담을 깨지 않는다. `random_state` 고정. 결과를 산포도 이미지로 저장해 눈으로 확인.

**[5] load** — 전체 사전 엔트리를 `on_map=true`와 좌표를 포함해 넣는다. 사전에 없는 런타임 추측만 `on_map=false`다. **재적재 가능(idempotent)** 하게: `(word, sense_no)` 유니크로 upsert 또는 truncate 후 재삽입. 배치 삽입(`execute_values`) 사용. ivfflat 인덱스는 데이터 적재 후 생성.

## 하지 말 것

- 국립국어원 포맷 확인 없이 파서 추측 작성
- 표제어만 임베딩해 동음이의어 뭉개기
- 지도 좌표를 요청마다 또는 매일 다시 생성하기
- 산출물을 파일로 안 남기고 메모리에서 한 번에 처리
- 라이선스 미확인 모델 사용
